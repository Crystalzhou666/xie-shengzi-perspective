# 谢胜子 · 思维操作系统 Skill

> 「思想输出是最高生态位，远大于干货。」——谢胜子

这是一个基于 [女娲（Nuwa）框架](https://github.com/alchaincyf/nuwa-skill) 蒸馏的 **谢胜子思维视角 Skill**，可在支持 Manus Skill 的 AI Agent 中激活，以谢胜子的思维框架和表达方式分析问题。

---

## 关于谢胜子

谢胜子（英文名 Since），华威商学院毕业，ACCA 持证，曾在国际四大会计师事务所工作，后跨界区块链、教育、媒体。现为内容创作者、小响声文化创始人、上海市作家协会会员。

- 2018 年《一站到底》单期冠军，入选名人堂
- 2020 年福布斯中国 U30
- 2021 年胡润百富 U30 创业领袖
- 著有《无界成长》（文汇出版社，2020）
- 虎嗅年度作者、36氪最受欢迎作者
